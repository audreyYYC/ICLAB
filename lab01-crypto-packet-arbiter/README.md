# Lab 01 — Multi-Precision Crypto/Packet Arbiter

An introductory RTL exercise focused on cycle-accurate control, input capture, arbitration, and multi-precision arithmetic. The design accepts structured transactions and schedules the requested processing while maintaining the required valid/ready behavior.

- Source: `src/MPCA.v`
- Skills: Verilog RTL, FSM design, arithmetic datapaths, protocol timing
