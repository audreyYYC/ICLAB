# Lab 06 — Poker and Win-Rate Calculator

Parameterized combinational/sequential logic evaluates poker hands and estimates winners or win rates across candidate cards. A Python generator supports independent stimulus and expected-result generation.

- RTL: `src/Poker.v`, `src/WinRate.v`
- Verification: `verification/gen.py`
- Skills: parameterized RTL, combinational ranking logic, Python reference generation

The Python utility was developed with AI assistance and reviewed and adapted by the author.
