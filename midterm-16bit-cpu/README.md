# Midterm Project — Custom 16-Bit CPU

A custom-instruction-set processor that fetches instructions, executes arithmetic/control operations, and communicates with external instruction/data memory using AXI-style channels. A Python utility generates initialized DRAM contents for verification.

- RTL: `src/CPU.v`
- Verification data generator: `verification/gen_DRAM.py`
- Skills: CPU microarchitecture, instruction decoding, memory protocols, hazard/control sequencing
