# ICLAB Digital IC Design Portfolio

Selected coursework from a semester-long integrated-circuit design laboratory. The repository follows the progression from RTL design and verification to synthesis-aware design, clock-domain crossing, SystemVerilog, and automatic place-and-route (APR).

## Repository policy

This is a curated portfolio, not a complete course distribution. It intentionally excludes problem statements, instructor testbenches, answer checkers, generated netlists, timing back-annotation, tool databases, standard-cell libraries, memory compilers, PDK data, server paths, and raw APR collateral. Foundry-specific SRAM names in two student RTL files were replaced by generic module names.

The Python generators were developed with AI assistance and then reviewed, adapted, and used for verification by the author.

See [NOTICE.md](NOTICE.md) before reusing any material. No open-source license is granted.
