# Lab 09 — SystemVerilog RPG Controller

A SystemVerilog design that manages player state, actions, dates, combat/training operations, and DRAM-backed records through a structured interface. It demonstrates typed data and more scalable verification-oriented RTL organization.

- RTL: `src/RPG.sv`
- Data generator: `verification/generate_dram.py`
- Skills: SystemVerilog, packages/interfaces, structured state, external-memory protocols

The course-owned type/package and testbench files are not included.
